使用说明

  1. 点击「🎤 开始调音」并允许麦克风权限（页面需在 https 或 localhost 下打开）。
  2. 拉奏或拨弦，页面实时显示音名、音分偏差（±50¢）与对应指法位置。
  3. 指法可视化：指板上金色脉动圆环是目标指法位置，绿色光点是当前音的指法位置；两者重合且变绿即代表拉对了音。
  4. 指针进入中间绿色区（±5¢ 内）即视为音准；绿色代表偏低，红色代表偏高。
  5. 点选琴弦、指法图格子或指板上的音可设定目标音，偏差将相对目标音计算，并可直接播放参考音对照。
  6. 建议在安静环境下练习；环境噪音过大时请靠近麦克风。

手机端：需通过 HTTPS 访问才能使用麦克风（可用 GitHub Pages / Netlify 等免费托管，或手机 Chrome 调试时通过 localhost 端口转发访问）。
